# Denúncia Digital

Sistema web desenvolvido para registro anônimo de violações de direitos humanos no ambiente digital.

O projeto foi criado como atividade extensionista com foco no tema:

> Direitos Humanos e o Universo Digital

e alinhado ao:

> ODS 16 – Paz, Justiça e Instituições Eficazes.

---

# Objetivo

O sistema tem como objetivo permitir que usuários realizem denúncias anônimas relacionadas a:

- Cyberbullying
- Discurso de ódio
- Exposição indevida
- Assédio online
- Golpes digitais
- Violação de privacidade
- Outras violações no ambiente virtual

Além disso, o projeto busca promover conscientização sobre direitos digitais, segurança online e cidadania digital.

---

# Tecnologias Utilizadas

- HTML5
- CSS
- JavaScript
- PHP
- MySQL
- Chart.js
- GitHub
- XAMPP

---

# Funcionalidades

- Registro anônimo de denúncias
- Dashboard com indicadores
- Integração com banco de dados MySQL
- Área informativa sobre direitos digitais
- Integração com Google Forms
- Layout responsivo
